## Lambda 내부 코드 구조

```
                    ┌─────────────────────────────────────┐
                    │          handler.py                  │
                    │          (접수처)                     │
                    │                                     │
                    │  event 수신                          │
                    │    ↓                                │
                    │  [필터 1] 내 메시지? → skip           │
                    │    ↓                                │
                    │  [필터 2] 파싱 실패? → skip           │
                    │    ↓                                │
                    │  [필터 3] 알람 아님? → skip           │
                    │    ↓                                │
                    │  [필터 4] OK 상태? → skip            │
                    │    ↓                                │
                    └────────────┬────────────────────────┘
                                 │
                                 ▼
                    ┌─────────────────────────────────────┐
                    │          utils.py                    │
                    │          (번역기)                     │
                    │                                     │
                    │  "msp-monitoring-dev-alb_unhealthy" │
                    │            ↓ 접두사 제거              │
                    │  "alb_unhealthy_host"               │
                    └────────────┬────────────────────────┘
                                 │
                                 ▼
                    ┌─────────────────────────────────────┐
                    │     playbooks/__init__.py            │
                    │     (안내판 = Registry)               │
                    │                                     │
                    │  "alb_target_5xx"     → Playbook A  │
                    │  "alb_unhealthy_host" → Playbook A  │
                    │  "ecs_running_low"    → (미구현)     │
                    └────────────┬────────────────────────┘
                                 │
                                 ▼
┌────────────────────────────────────────────────────────────────────┐
│                    playbooks/base.py                                │
│                    (계약서 = 양식)                                    │
│                                                                    │
│  ┌──────────────────────────────────────────────────────────────┐ │
│  │  BasePlaybook (추상)                                          │ │
│  │    - alarm_keys: list  → "내가 처리하는 알람 종류"               │ │
│  │    - run(): DiagnosisResult → "진단해서 결과 반환"              │ │
│  └──────────────────────────────────────────────────────────────┘ │
│                                                                    │
│  ┌──────────────────────────────────────────────────────────────┐ │
│  │  DiagnosisResult (dataclass)                                  │ │
│  │    - alarm_name      "무슨 알람?"                              │ │
│  │    - severity        "얼마나 급해?" (P1/P2/P3)                 │ │
│  │    - verdict         "판정 코드" (ALL_TARGETS_UNHEALTHY)       │ │
│  │    - summary         "한 줄 요약"                              │ │
│  │    - details         "상세 수치" {unhealthy: 2, total: 2}     │ │
│  │    - recommended_action  "뭘 해야 하나"                       │ │
│  └──────────────────────────────────────────────────────────────┘ │
└────────────────────────────────────────────────────────────────────┘
                                 │
                                 ▼
┌────────────────────────────────────────────────────────────────────┐
│              playbooks/alb_target_5xx.py                            │
│              (실제 진단 매뉴얼)                                       │
│                                                                    │
│  ┌─────────────────────────────────────────────────────────────┐  │
│  │  1. _check_target_health()                                   │  │
│  │     └─ elbv2.describe_target_health                          │  │
│  │        → healthy: 0, unhealthy: 2, reasons: [FailedHealth]   │  │
│  │                                                              │  │
│  │  2. _check_ecs_service()                                     │  │
│  │     └─ ecs.describe_services                                 │  │
│  │        → desired: 2, running: 1, deploying: false            │  │
│  │                                                              │  │
│  │  3. _check_logs()                                            │  │
│  │     └─ logs.filter_log_events (최근 5분, ERROR)               │  │
│  │        → 3건의 에러 로그                                       │  │
│  └─────────────────────────────────────────────────────────────┘  │
│                          ↓                                         │
│  ┌─────────────────────────────────────────────────────────────┐  │
│  │  4. _evaluate() — 의사결정 트리                                │  │
│  │                                                              │  │
│  │     unhealthy == total?                                      │  │
│  │       YES → P1: ALL_TARGETS_UNHEALTHY                        │  │
│  │                  "전부 죽음. 즉시 에스컬레이션"                   │  │
│  │       NO ↓                                                   │  │
│  │     unhealthy > 0?                                           │  │
│  │       YES → P2: PARTIAL_TARGETS_UNHEALTHY                    │  │
│  │              배포중? → "롤백 문의"                               │  │
│  │              아니면  → "모니터링 지속"                           │  │
│  │       NO ↓                                                   │  │
│  │     → P2: TARGETS_HEALTHY_APP_ERROR                          │  │
│  │            "서버 정상인데 5xx. 앱 코드 문제"                     │  │
│  └─────────────────────────────────────────────────────────────┘  │
└────────────────────────────────────────────────────────────────────┘
                                 │
                                 ▼
                    ┌─────────────────────────────────────┐
                    │         notifier.py                  │
                    │         (발송 담당)                    │
                    │                                     │
                    │  DiagnosisResult 수신                │
                    │    ├─→ SNS publish (Email)          │
                    │    └─→ Slack webhook (Block Kit)    │
                    └─────────────────────────────────────┘
```

## 무한루프 방지 메커니즘

```
                    ┌──────────────┐
                    │  CloudWatch  │
                    │  ALARM!      │
                    └──────┬───────┘
                           │
                           ▼
              ┌────────────────────────┐
              │  SNS Topic (P1P2)      │◀─────────────────────┐
              └─────┬──────────────────┘                      │
                    │                                         │
                    ▼                                         │
              ┌────────────────────────┐                      │
              │  Lambda (handler.py)   │                      │
              │                        │                      │
              │  Subject 확인:          │     ┌─────────────────────────┐
              │  "[Runbook]"로 시작?    │     │  이건 별도 토픽으로 보냄    │
              │                        │     │  (runbook-results)       │
              │  YES → skip (무한루프   │     │  그래도 방어적으로 체크    │
              │         방지!)          │     └─────────────────────────┘
              │  NO → 진단 실행         │                      │
              │        ↓               │                      │
              │  결과를 SNS에 publish   │──────────────────────┘
              │  Subject: "[Runbook]   │
              │   P1 - alarm_name"     │
              └────────────────────────┘
```

## 데이터 흐름 (Terraform ↔ Python 연결)

```
┌─ Terraform 세계 ──────────────────────────────────────────────────┐
│                                                                    │
│  alarms.auto.tfvars                                               │
│    each.key = "alb_unhealthy_host"                                │
│         ↓                                                         │
│  modules/alarms/main.tf                                           │
│    alarm_name = "msp-monitoring-dev-" + "alb_unhealthy_host"      │
│                  └─ var.project ─┘└env┘   └─── each.key ───┘     │
│         ↓                                                         │
│  modules/runbook/main.tf                                          │
│    environment variables = {                                       │
│      PROJECT = "msp-monitoring"                                   │
│      ENVIRONMENT = "dev"                                          │
│      TARGET_GROUP_ARN = "arn:aws:..."                             │
│    }                                                              │
│                                                                    │
└────────────────────────────────┬───────────────────────────────────┘
                                 │ Lambda 배포 시 환경변수 주입
                                 ▼
┌─ Python 세계 ─────────────────────────────────────────────────────┐
│                                                                    │
│  handler.py                                                        │
│    alarm_name = "msp-monitoring-dev-alb_unhealthy_host"            │
│         ↓                                                         │
│  utils.py                                                          │
│    prefix = os.environ["PROJECT"] + "-" + os.environ["ENVIRONMENT"]│
│    # = "msp-monitoring-dev-"                                       │
│    alarm_key = alarm_name.removeprefix(prefix)                     │
│    # = "alb_unhealthy_host"                                        │
│         ↓                                                         │
│  PlaybookRegistry                                                  │
│    _PLAYBOOKS["alb_unhealthy_host"] → AlbTarget5xxPlaybook         │
│         ↓                                                         │
│  alb_target_5xx.py                                                 │
│    target_group_arn = os.environ["TARGET_GROUP_ARN"]                │
│    # Terraform이 넣어준 값으로 AWS API 호출                          │
│                                                                    │
└────────────────────────────────────────────────────────────────────┘
```
